`build_marketing_36.py` rebuilds the two HTML files from the earlier local marketing v3 deck. It expects that source at `~/Project/BP/Melooloo_Deck_Pemasaran_Web_v3_23Okt2026/index.html`. The published HTML and images are self-contained and do not need the script at runtime.
